## ai-sentinel

Scans Confluence spaces for personal data, stores every finding encrypted, and lets an operator
triage it or redact it in place. Three services — `pii-reporting-ui/` (Angular),
`pii-reporting-api/` (Java/Spring Boot), `pii-detector-service/` (Python/gRPC) — sharing one gRPC
contract and one PostgreSQL database. Generated documentation is in `openwiki/`, contributor setup
and coding standards in `CONTRIBUTING.md`, recorded lessons in `lessons.md`.

## Policy

- Never push to `main` or `develop`. Branch from `develop` as `feature/…` or `bugfix/…` and open a
  PR against `develop`; `main` takes releases only.
- Never hand-edit `openwiki/` — it is generated by `headroom-ai`. Fix the source and regenerate.
- `.devcontainer/.db-encryption-key` is a throwaway dev key committed on purpose; do not report it
  as a leak.

## Where things are

- The only cross-service contract is `proto/pii_detection.proto`; changing it touches all three.
- Per-service instructions: `pii-detector-service/AGENTS.md`, `pii-reporting-api/AGENTS.md`,
  `pii-reporting-ui/AGENTS.md`
- Start from `openwiki/quickstart.md` — it lists which hand-written docs are stale and must not be
  trusted, root `README.md` included.
- Before touching scan status, read `qa/scan-status-bugs/FIXES-REPORT.md`; it explains why the
  current semantics are what they are.

## Running and verifying

- CI runs unit tests only, per service (`.github/workflows/run-tests.yml`). Integration tests never
  run there — run them locally before calling a change safe.
- Root `package.json` is npm and holds only the doc generator. Every frontend command runs inside
  `pii-reporting-ui/`, with pnpm.

## Conventions that differ from defaults

- Which detectors run, which PII types are kept and at which threshold live in PostgreSQL, not in
  code or in a config file.
- Put filtering, sorting, search and facets on the server, even when the volume would make
  client-side filtering sufficient.

## Known pitfalls

- Compute the active PII types as the conjunction of the global flags in `pii_detection_config` and
  the per-type rows in `pii_type_config`: a row with `enabled=true` is inert when its detector is
  off globally. Reading `pii_type_config` alone reports types that never run.
