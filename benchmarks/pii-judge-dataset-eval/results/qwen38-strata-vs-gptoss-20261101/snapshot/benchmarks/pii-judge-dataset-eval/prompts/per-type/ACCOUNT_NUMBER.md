TYPE = ACCOUNT_NUMBER (Numero de compte) : la partie domestique d'un compte bancaire ou postal, telle que l'etablissement la numerote dans son pays.
FORMAT : il n'existe aucune specification commune. La longueur, l'alphabet et le decoupage changent d'un pays a l'autre, et beaucoup d'etablissements ajoutent leur propre numerotation interne. Le motif (a) est donc presque toujours interdit : ne rejette ni sur la longueur, ni sur la presence de lettres, ni sur les espaces ou les tirets, et dans le doute sur la specification nationale, c'est UNSURE. Une seule exception, ou aucune numerotation nationale ne peut convenir : un montant ecrit avec separateurs de milliers et decimales, qui est une somme d'argent et non un compte. Une valeur courte n'est pas un motif de rejet : aux Etats-Unis un compte va de quatre a dix-sept chiffres, et les caisses de credit en delivrent couramment a quatre ou cinq ; au pire UNSURE, jamais FALSE_POSITIVE.
TYPES CONCURRENTS A NOMMER : un rejet au titre du motif TYPE CONCURRENT exige que le contexte proche nomme lui-meme ce type ; quand la valeur seule ne tranche pas et que rien ne le nomme, c'est UNSURE, jamais FALSE_POSITIVE.
- un code d'identification d'etablissement, qui designe la banque et jamais le compte ;
- un numero de routage, de guichet ou de banque, qui designe l'agence dans un systeme de compensation ;
- un numero de carte de paiement ;
- un identifiant client ou un numero de contrat, de facture, de dossier ou de reference de paiement ;
- un matricule employe ou un identifiant interne de personnel ;
- un numero de compte comptable ou un code de plan comptable.
CE QUI RESTE TRUE_POSITIVE : la partie domestique seule, meme quand le contexte parle d'IBAN, l'identifiant international etant une forme plus precise du meme compte et non un type incompatible ; seule une valeur extraite qui porte elle-meme le code de pays et les deux chiffres de controle releve du type IBAN ; un numero nu, sans mot-cle qui le nomme, hors de tout contexte bancaire, au pire UNSURE, jamais FALSE_POSITIVE ; un numero ecrit par blocs ou d'un seul tenant ; le compte d'un service, d'une entreprise ou d'une collectivite, le motif (d) ne s'appliquant pas a un numero ; un numero cite sans titulaire, sans banque et sans devise ; un numero d'un exemple de documentation ou d'un jeu de donnees de test.
ATTENTION AU PIEGE INVERSE : la locution qui nomme le type, en francais comme en anglais, n'est pas une valeur. Un span reduit a cette locution, ou a un libelle de champ suivi de deux points, releve du motif (c), meme si une vraie valeur se trouve juste apres dans le contexte. Idem pour une valeur masquee, un gabarit entre crochets ou accolades, ou une reference de variable non resolue.
