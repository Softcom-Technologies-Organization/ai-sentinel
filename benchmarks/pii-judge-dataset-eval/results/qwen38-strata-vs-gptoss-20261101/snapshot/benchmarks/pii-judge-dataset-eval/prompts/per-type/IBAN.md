TYPE = IBAN (Identifiant bancaire international (IBAN)) : l'identifiant normalise qui designe un compte bancaire pour les virements entre pays.
FORMAT : spec ISO 13616, stable et verifiable : deux lettres de code pays, puis deux chiffres de controle, puis l'identifiant national du compte ; de 15 a 34 caracteres alphanumeriques au total, espaces et tirets ignores. Une suite de chiffres seule, sans les deux lettres de pays en tete, n'est donc jamais un IBAN, pas plus qu'un montant decoupe en groupes de chiffres. La longueur exacte varie selon le pays : ne rejette pas sur une longueur nationale que tu ne connais pas, et ne verifie jamais la cle de controle toi-meme.
Le mot IBAN, ou une locution comme "numero IBAN" ou "international bank account number", nomme le type : ce n'est pas une valeur. Un gabarit ou une valeur masquee non plus.
TYPES CONCURRENTS A NOMMER : le motif TYPE CONCURRENT ne vaut que si le contexte NOMME le type rival dans les mots qui entourent la value ; sans cette mention, reponds UNSURE et jamais FALSE_POSITIVE. Les cas ci-dessous qui relevent des motifs VIOLATION DE FORMAT ou PAS UNE VALEUR gardent leur propre motif et n'ont pas besoin de cette mention.
- un numero de compte national nu (BBAN), ecrit sans le prefixe de deux lettres de pays : il viole la spec ISO 13616 et se rejette au motif VIOLATION DE FORMAT, sans que le contexte ait a nommer le type rival ;
- un code d'identification d'etablissement BIC ou SWIFT, ouvert par quatre lettres et long de huit ou onze caracteres (ISO 9362) ;
- un numero de routage bancaire, un code guichet ou un code d'agence purement numerique ;
- un numero de carte de paiement, de huit a dix-neuf chiffres ;
- une reference de paiement, un numero de bulletin de versement ou un identifiant de dossier commencant par deux lettres.
CE QUI RESTE TRUE_POSITIVE : l'IBAN d'une entreprise, d'un service ou d'une collectivite ; un IBAN ecrit par blocs ou d'un seul tenant ; un IBAN d'exemple de documentation ou d'un jeu de test. Une valeur conforme a la spec posee toute seule, sans le mot IBAN autour et sans nom de titulaire, reste TRUE_POSITIVE : l'absence de mot-cle n'est pas un motif de rejet. Le motif PAS UNE PERSONNE ne s'applique pas a un numero de compte.
