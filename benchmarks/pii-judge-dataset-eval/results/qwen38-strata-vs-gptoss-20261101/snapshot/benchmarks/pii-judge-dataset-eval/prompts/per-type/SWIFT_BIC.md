TYPE = SWIFT_BIC (Code BIC/SWIFT) : le code normalise qui identifie un etablissement financier dans les echanges interbancaires.
FORMAT : norme ISO 9362, exactement huit ou onze caracteres alphanumeriques sans espace : quatre lettres d'etablissement, deux lettres de pays, deux caracteres de localite, puis trois caracteres facultatifs d'agence. Cette specification est internationale et stable, donc le motif VIOLATION DE FORMAT est ici autorise : une suite de trois a sept lettres est trop courte, une suite de chiffres seule ne peut pas commencer par quatre lettres, et toute longueur autre que huit ou onze est impossible.
TYPES CONCURRENTS A NOMMER : le motif TYPE CONCURRENT ne vaut que si le contexte NOMME le type rival dans les mots qui entourent la value ; sans cette mention, reponds UNSURE et jamais FALSE_POSITIVE. Les cas ci-dessous qui relevent des motifs VIOLATION DE FORMAT ou PAS UNE VALEUR gardent leur propre motif et n'ont pas besoin de cette mention.
- l'intitule qui annonce le champ, dans une etiquette de formulaire, une entete de colonne ou une phrase, plutot que le code lui-meme : c'est le NOM du champ et non son contenu, motif PAS UNE VALEUR ;
- une valeur deja masquee, un gabarit entre crochets ou entre accolades, une reference de variable d'environnement non resolue ;
- un identifiant international de compte bancaire (IBAN), qui commence aussi par des lettres mais place deux chiffres de controle en troisieme et quatrieme position et depasse onze caracteres ;
- un numero de compte national ou interne a un etablissement, purement numerique ou commencant par des chiffres : un tel enchainement ne peut pas ouvrir sur quatre lettres, motif VIOLATION DE FORMAT, sans que le contexte ait a nommer le type rival ;
- un numero de routage, de guichet ou de banque propre a un systeme national de paiement ;
- un acronyme quelconque en majuscules : code d'aeroport, de compagnie, de devise, de pays, de produit, d'application, de projet ou de service.
CE QUI RESTE TRUE_POSITIVE : un code nu, sans nom de banque, sans mot-cle et sans compte a cote, reste valide ; la forme a huit caracteres n'est pas une version tronquee de celle a onze, les deux sont completes ; un code ecrit en minuscules ou colle aux autres champs d'un ordre de virement ; un code d'exemple de documentation ou d'un jeu de donnees de test. Le motif PAS UNE PERSONNE ne s'applique jamais ici : ce code designe un etablissement financier.
