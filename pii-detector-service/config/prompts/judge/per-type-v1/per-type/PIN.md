TYPE = PIN (Code PIN) : le code confidentiel, compose de chiffres, qui authentifie le porteur d'une carte bancaire, d'une carte SIM, d'un compte ou d'un acces.
FORMAT : quatre a douze chiffres, borne ISO 9564-1 ; aucune longueur unique ne s'impose, chaque emetteur fixe la sienne et le PIN de carte SIM monte jusqu'a huit chiffres. Le motif (a) est donc INTERDIT sur la seule longueur tant que la value tient dans cette fenetre : un code de quatre chiffres comme un code de huit ou de douze chiffres est un PIN valide. Le motif (a) ne reste ouvert que pour ce qu'aucun code confidentiel ne peut etre : une value qui n'est pas faite uniquement de chiffres, un nombre ecrit comme un montant avec separateur de milliers, decimales ou symbole monetaire, ou une suite de chiffres qui depasse douze chiffres et qui releve alors d'un identifiant ou d'un numero de compte.
TYPES CONCURRENTS A NOMMER, le motif (b) n'etant recevable que si le contexte NOMME le type concurrent a proximite immediate de la value ; s'il ne le nomme pas, reponds UNSURE :
- la LOCUTION QUI NOMME LE TYPE prise pour une valeur : le libelle d'un champ, d'une colonne, d'un parametre ou d'une rubrique de formulaire cite sans son contenu, en francais comme en anglais ; c'est le motif (c), et c'est le rejet le plus frequent sur ce type ;
- un placeholder, un gabarit de documentation, une reference de variable non resolue ou une valeur deja masquee par des etoiles ou des croix ;
- un cryptogramme de carte de paiement, nomme comme tel dans le contexte, qui releve du type CVV ;
- un code postal, y compris a quatre chiffres comme en Suisse, ou un indicatif telephonique ;
- un identifiant client, un numero de compte, de dossier, de contrat ou de reference de paiement ;
- une annee, un exercice, un montant, un effectif, un numero de version ou un code de statut ;
- un numero de salle, de casier, d'etage, de badge ou de ligne dans une liste.
CE QUI RESTE TRUE_POSITIVE : un code par defaut, un code de mise en service, un code d'un lot de cartes ou d'un environnement de test ; un PIN de carte SIM a huit chiffres ; un code cite dans une procedure ou une consigne ; un code accompagne d'un mot-cle dans n'importe quelle langue du document ; et surtout une VALEUR NUE, une suite de quatre a douze chiffres sans aucun mot-cle autour, que le contexte n'attribue a aucun autre type : l'absence d'indice contextuel ne rejette rien, c'est TRUE_POSITIVE. Si le contexte est ambigu entre un PIN et un voisin sans le designer explicitement, reponds UNSURE. Le motif (d) PAS UNE PERSONNE ne s'applique jamais a un code confidentiel.
